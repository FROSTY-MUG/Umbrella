## 🔬 Scientific Core Modules & Detailed Walkthrough

### 1. 🧬 Genome Competitor & 3D Double Helix Topology
- **Multi-Organism Comparison Engine**: Evaluates double-strand (DS) query genetic samples against verified competitor banks:
  - *Escherichia coli K-12 MG1655* (Gram-negative model)
  - *Pseudomonas putida KT2440* (Metabolic / Environmental efflux model)
  - *Bacteriophage T4* (Myoviridae virulent injectosome)
  - *Bacteriophage Lambda* (Temperate lysogenic recombinase model)
  - *Saccharomyces cerevisiae* (Eukaryotic fungal membrane model)
- **Interactive 3D Double Helix Visualization**:
  - Parametric anti-parallel helical strands ($5' \rightarrow 3'$ sense in bio-emerald and $3' \leftarrow 5'$ antisense in electric cyan).
  - Accurate Watson-Crick base-pairing (A-T with 2 hydrogen bonds, G-C with 3 hydrogen bonds).
  - Depth-sorted 3D perspective with continuous rotation, speed modulation, and zoom controls.
  - **Dynamic Breakage Locus Rupture**: Highlights vulnerable chromosomal cleavage points (e.g., $gyrA$ quinolone pocket, $ftsI$ catalytic loop, $attB$ integration hub) with animated stress flares.
  - Interactive base-pair inspector displaying coordinates, thermodynamic binding $\Delta G$, and local damage indices.

### 2. 🧪 Science Lab (Cellular Stress & DNA Breakage Simulator)
- **5 Environmental Stress Challenge Modalities**:
  - *Oxidative Radicals*: $H_2O_2$ / hydroxyl free radicals inducing 8-oxoG transversions.
  - *Thermal Shock*: $42^\circ\text{C}-50^\circ\text{C}$ protein unfolding and replication fork stalls.
  - *Osmotic Hypertonicity*: $1.5\text{M NaCl}$ plasmolysis, turgor pressure collapse, and desiccation.
  - *Heavy Metal Toxicity*: $\text{Cd}^{2+} / \text{Cu}^{2+}$ cofactor displacement and envelope stress.
  - *Ionizing Radiation*: $5-25\text{ Gy}$ Compton scattering and double-strand chromosomal fragmentation.
- **Dynamic Kinetic Playback**: Real-time simulation engine with Start, Pause, and Step controls computing DNA double-strand integrity (%), reactive stress flux (%), cellular repair load (%), and colony survival viability (%).
- **Adaptive ASCII Cellular Matrix**: Dynamically adjusts visual cytomatrix rendering based on the selected stress agent.

### 3. 📊 Analysis Studio (Tabular Analytics & Cohort Charts)
- **Cohort Dataset Selection**: Switch dynamically between *Global BV-BRC Isolates ($n=1,500$)*, *Klebsiella pneumoniae Carbapenem Panel ($n=480$)*, and *Acinetobacter baumannii Surveillance ($n=320$)*.
- **Drug Susceptibility AST Stacked Bars**: Real-time distribution across Ciprofloxacin, Meropenem, Ceftriaxone, Gentamicin, Colistin, and Piperacillin/Tazobactam with CLSI M100-ED34 breakpoint markers.
- **AMR Determinant Prevalence**: Frequency distributions for high-threat resistance genes ($bla_{KPC-2}$, $bla_{NDM-1}$, $gyrA\text{-}S83L$, $parC\text{-}S80I$, $mcr\text{-}1$, $tet(X4)$, $armA$) with plasmid vs chromosomal indicators and resistance odds ratios.
- **Gene-Phenotype Correlation Heatmap**: Pairwise Pearson correlation matrix ($r$) mapping genotypes to phenotypic clinical resistance.
- **Parquet Feature Matrix Explorer**: Full searchable data table with non-zero sparsity counts, dtypes, and importance rankings.
- **Real Data Export**: Direct one-click download for both formatted CSV and structured JSON dossiers.

### 4. 📝 Research Desk (Persistent Scientific Context)
- **Active Workspace Isolate Binding**: Automatically links active samples from the *Sample Vault* to maintain context across all desktop windows.
- **Hypothesis Lifecycle Tracker**: Propose, categorize, and update working hypotheses across 4 verifiable states: `TESTING`, `VALIDATED`, `PENDING`, and `DISPROVEN` with live confidence scoring.
- **Lab Observation Logs**: Structured, timestamped observation logger categorizing entries under `[GENOMICS]`, `[PHENOTYPE]`, `[MIC_ASSAY]`, and `[BIOINFORMATICS]`.
- **Peer-Reviewed Literature Dossier**: Curated references (NCBI AMRFinderPlus, Lancet Global AMR, Goodhead Biophysics) with DOI links and key empirical takeaways.
- **Dossier Markdown Export**: Generates an auditable, peer-review-ready markdown dossier (`.md`) summarizing the active investigation.

### 5. 💻 Bio-Terminal (Sandboxed Bioinformatics CLI)
- **32 In-Browser Allowlisted Commands**:
  - `help`, `status`, `pwd`, `ls`, `cd`, `cat`, `head`, `tail`, `grep`, `find`, `wc`, `echo`, `date`, `whoami`, `history`, `env`, `df`, `du`, `ps`, `top`, `curl`, `wget`, `ping`, `nslookup`, `git`, `python`, `pip`, `train`, `predict`, `export`, `jobs`, `clear`.
- **Security Boundaries**: Real-time sanitization preventing shell escapes, privilege escalation (`sudo`), and destructive patterns (`rm -rf`, fork bombs).
- **Execution Provenance**: All executed commands are logged with actor identity, execution duration, and cryptographic audit hashes.

### 6. 🤖 120 GB AMR ML Training Pipeline
- **Out-of-Core Processing**: DuckDB and PyArrow engine streaming multi-gigabyte Parquet datasets without high memory spikes.
- **Machine Learning Architectures**: Versioned pipelines supporting XGBoost, Random Forest, and 1D-CNN sequence encoders with Stratified 5-Fold cross-validation.
- **Comprehensive Evaluation**: Metrics including AUROC ($>0.90$), PR-AUC, F1-Score, Precision, Recall, and Confusion Matrices.

## 🚀 Local Quickstart & Development

### Prerequisites
- Node.js 18+ and `pnpm` (or `npm`)
- Python 3.10+
- Git

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/Skeletor-Pirate/Umbrella.git
cd Umbrella

# Install frontend dependencies
pnpm install
```

### 2. Run the Backend API
```bash
# Create and activate Python virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install Python requirements
pip install -r requirements.txt

# Start the FastAPI engine
uvicorn services.api.main:app --host 0.0.0.0 --port 8000 --reload
```

### 3. Run the Desktop Frontend
```bash
# In a separate terminal
pnpm --filter @umbrella/desktop dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser. Enter passcode `05872610` to unlock.

## 🔒 Security, Compliance & Scientific Limitations

1. **Non-Pathogenic & Synthetic Scope**: All bioinformatics reference models, PDB structures, and sequences use public, curated, non-pathogenic research organisms (e.g. *E. coli K-12*, *P. putida*, *Bacteriophage T4*, *Yeast*).
2. **Computational Simulation Disclaimer**: All predictions, structural breakage loci, and stress response curves are mathematical approximations derived from algorithmic models (Modified Gompertz kinetics, nucleotide alignment matrices, and trained ML classifiers). They are intended for **research, education, and simulation only**, not for clinical diagnosis or medical treatment.
3. **Audit Integrity**: User logins and terminal command executions are cryptographically recorded with immutable timestamps and session identifiers.
